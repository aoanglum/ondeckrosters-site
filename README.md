# On Deck Rosters site

Static marketing site for the On Deck Rosters iOS app, served via GitHub
Pages at `ondeckrosters.app`.

- `index.html` - landing page
- `privacy.html` - privacy policy (linked from App Store Connect)
- `support.html` - support page (linked from App Store Connect)
- `styles.css` - shared brand tokens (colors/fonts), matched to the app's
  `Theme.swift` (dark, near-black) and the app icon's blue/green mark
- `assets/` - logo and favicons rendered from `ondeck-icon.svg`

Brand colors: `#1d4ed8` (blue), `#4ade80` (green), `#0a0a0a` (background).
Display font: Fredoka (Google Fonts). Body font: system font stack.

`support@ondeckrosters.app` is used as the contact address on the privacy
and support pages - set up email forwarding for the domain (or swap in a
real address) before this goes live.
